# Algoritmi in chiaro

Sito statico in italiano: un ripasso pratico di algoritmi e strutture dati per chi li ha studiati all'università e nel lavoro li ha un po' persi di vista. Ogni scheda ha l'idea, dove torna utile sul lavoro, pseudocodice, codice JavaScript/TypeScript/Python, complessità, una visualizzazione interattiva ed esercizi.

Pubblicato con GitHub Pages dalla radice del branch `main`. In locale:

```bash
python3 -m http.server 8080
```

## Schede

- `pagine/complessita.html` — notazione asintotica
- `pagine/ricerca-binaria.html`
- `pagine/bubble-sort.html`, `pagine/merge-sort.html`, `pagine/quick-sort.html`
- `pagine/bfs.html` (iterativa con coda, ricorsiva per livelli), `pagine/dfs.html` (ricorsiva, iterativa con pila)
- `pagine/mappa.html`, `pagine/fonti.html`
