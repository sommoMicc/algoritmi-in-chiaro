Ordinamento

Bubble Sort

L'algoritmo più raccontato nelle prime lezioni: confronti adiacenti, scambi, e i valori grandi che «salgono a galla» verso la fine dell'array. Non è il più veloce, ma è un ottimo microscopio su cosa significa ordinare.

Tempo O(n²) Spazio O(1) Stabile In-place

L'idea

Scorri l'array da sinistra a destra e, ogni volta che due vicini sono fuori ordine, li scambi. Alla fine del primo giro il valore più grande è arrivato in ultima posizione: è «venuto a galla», da cui il nome. Al giro successivo puoi ignorare quell'ultima cella, e così via. Dopo al più n − 1 passate l'array è ordinato.

Una piccola ottimizzazione cambia il caso migliore. Se in una passata non avviene nessuno scambio, l'array è già in ordine e puoi uscire subito. Senza questa bandierina, Bubble Sort fa sempre Θ(n²) confronti, anche su una sequenza già ordinata.

Sul lavoro, onestamente

Non lo scriverai in produzione. Ma è il modo più rapido per ritrovare il vocabolario: confronti, scambi, stabilità, in-place, uscita anticipata. E ti aiuta a riconoscere il pattern «doppio ciclo che confronta vicini» quando spunta, travestito, in qualche script.

Provalo tu

Avvia l'animazione, rallenta, oppure vai avanti un confronto alla volta. Il giallo è un confronto, il terracotta uno scambio, il verde una posizione ormai definitiva.

Pseudocodice e codice

BUBBLE-SORT(A)
  n ← lunghezza(A)
  per i da 0 a n − 2
    scambiato ← falso
    per j da 0 a n − 2 − i
      se A[j] > A[j + 1]
        scambia A[j] e A[j + 1]
        scambiato ← vero
    se scambiato = falso
      termina
function bubbleSort(a) {
  const v = a.slice();
  const n = v.length;
  for (let i = 0; i < n - 1; i++) {
    let scambiato = false;
    for (let j = 0; j < n - 1 - i; j++) {
      if (v[j] > v[j + 1]) {
        [v[j], v[j + 1]] = [v[j + 1], v[j]];
        scambiato = true;
      }
    }
    if (!scambiato) break;
  }
  return v;
}
def bubble_sort(a):
    v = list(a)
    n = len(v)
    for i in range(n - 1):
        scambiato = False
        for j in range(n - 1 - i):
            if v[j] > v[j + 1]:
                v[j], v[j + 1] = v[j + 1], v[j]
                scambiato = True
        if not scambiato:
            break
    return v

Complessità

TempoSpazio extra
Caso migliore (già ordinato, con bandierina)Θ(n)O(1)
Caso medio e peggioreΘ(n²)O(1)

Nel caso peggiore — per esempio un array in ordine inverso — ogni passata fa circa n − i confronti e quasi altrettanti scambi. Sommando le passate ottieni n(n−1)/2 confronti: Θ(n²). Lo spazio extra è costante: si lavora nell'array stesso (in-place).

Bubble Sort è stabile: due elementi uguali restano nello stesso ordine relativo, perché si scambia solo se il primo è strettamente maggiore del secondo. È una proprietà utile quando ordini record già sistemati secondo un altro campo.

Quando usarlo, e quando no

Per array reali si preferiscono Merge Sort, Heap Sort o (con accortezze) Quick Sort, tutti O(n log n) nel caso che conta. Bubble Sort resta didattico: è corto da scrivere, facile da visualizzare, e rende immediato il salto di qualità quando poi incontri Merge Sort. In produzione, se ti serve un ordinamento semplice su poche decine di elementi, Insertion Sort è di solito una scelta migliore: è anch'esso quadratico nel peggiore, ma fa meno scriviture e approfitta meglio di input quasi ordinati.

Esercizi

1. Dopo la prima passata

Parti da [4, 3, 5, 1, 2]. Com'è l'array alla fine della prima passata completa?

Mostra la soluzione

[3, 4, 1, 2, 5]. Gli scambi: 4↔3, poi 5↔1, poi 5↔2. Il 5 è in fondo, come previsto.

2. Quanti scambi?

Sull'array [3, 2, 1], quanti scambi fa Bubble Sort (versione con bandierina)?

Mostra la soluzione

Tre. Prima passata: 3↔2 dà [2, 3, 1], poi 3↔1 dà [2, 1, 3]. Seconda passata: 2↔1 dà [1, 2, 3]. Terza passata: nessun scambio, si esce. I confronti sono più degli scambi: la bandierina evita una passata inutile, non i confronti già fatti.

3. Stabilità

Perché il confronto deve essere > e non ≥ se vogliamo uno sort stabile?

Mostra la soluzione

Con ≥ due elementi uguali verrebbero scambiati, e il secondo passerebbe davanti al primo. Con > gli uguali restano dove sono, e l'ordine relativo si conserva.
