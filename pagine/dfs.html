Grafi

DFS, visita in profondità

Imbocchi un ramo e lo segui finché puoi, poi torni indietro all'ultimo bivio e provi la strada successiva. È il modo in cui si esce da un labirinto con il gomitolo, e il modo in cui il tuo programma attraversa un albero ricorsivo.

Tempo O(V + E) Spazio O(V) Pila LIFO Ricorsiva o iterativa

L'idea

Dalla partenza, vai sul primo vicino non ancora visitato, poi sul primo vicino di quello, e così via. Quando un nodo non ha più vicini nuovi, torni indietro (backtracking) e riprendi da dove avevi lasciato. Per ricordarti «dove avevi lasciato» serve una pila: nella versione ricorsiva è lo stack delle chiamate, nella versione iterativa la gestisci tu.

Se la confronti con la BFS, la differenza è tutta qui: coda contro pila. La BFS si allarga, la DFS si allunga.

Dove la rivedi sul lavoro

Risolvere le dipendenze di un package manager o di un build system, e trovare i cicli (la classica «circular dependency»). L'ordinamento topologico per decidere in che ordine eseguire migration, job o task. Attraversare un DOM, un AST o un filesystem. Le componenti connesse in un grafo. E tutti i problemi di backtracking: sudoku, permutazioni, ricerche esaustive con potatura.

Provalo tu

Confronta le due versioni sullo stesso nodo di partenza: l'ordine di visita è identico, cambia solo chi tiene la pila. Nella ricorsiva vedi la catena delle chiamate aperte, nell'iterativa il contenuto della pila esplicita (la cima è a destra).

Versione ricorsiva

È la più corta e la più vicina alla definizione. Il «torno indietro» è gratis: quando la chiamata su un vicino finisce, il controllo ritorna al ciclo del nodo precedente.

function dfs(grafo, u, visti = new Set(), ordine = []) {
  visti.add(u);
  ordine.push(u);
  for (const v of grafo[u]) {
    if (!visti.has(v)) dfs(grafo, v, visti, ordine);
  }
  return ordine;
}
type Grafo = Record<string, string[]>;

function dfs(
  grafo: Grafo,
  u: string,
  visti: Set<string> = new Set(),
  ordine: string[] = []
): string[] {
  visti.add(u);
  ordine.push(u);
  for (const v of grafo[u] ?? []) {
    if (!visti.has(v)) dfs(grafo, v, visti, ordine);
  }
  return ordine;
}
def dfs(grafo, u, visti=None, ordine=None):
    if visti is None:
        visti, ordine = set(), []
    visti.add(u)
    ordine.append(u)
    for v in grafo[u]:
        if v not in visti:
            dfs(grafo, v, visti, ordine)
    return ordine

Il limite della ricorsione

La profondità della ricorsione può arrivare a V: su una catena di 100.000 nodi Python solleva RecursionError (il limite predefinito è circa 1.000) e Node.js va in «Maximum call stack size exceeded». Con dati reali e grandi, o non controllati da te, preferisci la versione iterativa.

Versione iterativa, con pila esplicita

Sostituisci lo stack delle chiamate con un array usato come pila: push per inserire, pop per estrarre dalla cima, entrambi O(1). Due dettagli la rendono equivalente alla ricorsiva:

  • segna il nodo come visitato quando lo estrai, e ignora quelli già visitati: un nodo può trovarsi in pila più volte, ma lo visiti una sola;
  • inserisci i vicini in ordine inverso, così il primo vicino finisce in cima e viene esplorato per primo, come nella ricorsiva.
function dfsIterativa(grafo, partenza) {
  const visti = new Set();
  const ordine = [];
  const pila = [partenza];
  while (pila.length > 0) {
    const u = pila.pop();
    if (visti.has(u)) continue;           // già visitato da un altro ramo
    visti.add(u);
    ordine.push(u);
    for (const v of [...grafo[u]].reverse()) {
      if (!visti.has(v)) pila.push(v);
    }
  }
  return ordine;
}
function dfsIterativa(grafo: Record<string, string[]>, partenza: string): string[] {
  const visti = new Set<string>();
  const ordine: string[] = [];
  const pila: string[] = [partenza];
  while (pila.length > 0) {
    const u = pila.pop()!;
    if (visti.has(u)) continue;
    visti.add(u);
    ordine.push(u);
    const vicini = grafo[u] ?? [];
    for (let i = vicini.length - 1; i >= 0; i--) {
      if (!visti.has(vicini[i])) pila.push(vicini[i]);
    }
  }
  return ordine;
}
def dfs_iterativa(grafo, partenza):
    visti, ordine = set(), []
    pila = [partenza]
    while pila:
        u = pila.pop()
        if u in visti:                   # già visitato da un altro ramo
            continue
        visti.add(u)
        ordine.append(u)
        for v in reversed(grafo[u]):
            if v not in visti:
                pila.append(v)
    return ordine

Complessità

VersioneTempoSpazio extra
RicorsivaO(V + E)O(V) visti + O(V) stack delle chiamate
Iterativa con pilaO(V + E)O(V) visti + pila fino a O(E) in questa forma

Ogni nodo viene visitato una volta e ogni lista di adiacenza scorsa una volta: tempo lineare, come la BFS. La versione iterativa qui sopra può mettere in pila lo stesso nodo più volte (una per ogni arco che lo raggiunge prima della visita), quindi la pila può crescere fino a O(E). Esiste una variante con un iteratore per nodo che resta in O(V), più lunga da scrivere; per un ripasso, questa è la forma da ricordare.

Esercizi

1. Ordine di visita

Nel grafo dell'animazione, partendo da A con i vicini in ordine alfabetico, in che ordine visita la DFS?

Mostra la soluzione

A, B, D, E, C, F, G. Da A scende su B, poi su D (vicolo cieco), torna a B e va su E, da E va su C (B è già visto), da C su F, poi torna fino a E e visita G.

2. Senza reverse

Cosa cambia se nella versione iterativa non inverti i vicini?

Mostra la soluzione

È ancora una DFS corretta, ma esplora per primo l'ultimo vicino: partendo da A ottieni A, C, F, E, G, B, D. Ordine diverso dalla ricorsiva, stessa complessità.

3. Trovare un ciclo

In un grafo orientato di dipendenze, come usi la DFS per accorgerti di una dipendenza circolare?

Mostra la soluzione

Tieni tre stati per nodo: non visitato, «in corso» (sulla pila delle chiamate) e completato. Se durante la visita incontri un arco verso un nodo «in corso», hai trovato un ciclo. L'ordine in cui i nodi diventano «completati», letto al contrario, è un ordinamento topologico quando cicli non ce ne sono.
