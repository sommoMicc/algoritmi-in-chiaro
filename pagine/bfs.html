Grafi

BFS, visita in ampiezza

Parti da un nodo, visiti tutti i suoi vicini, poi i vicini dei vicini, e così via, a cerchi concentrici. Lo strumento è una coda. Il regalo è che, se gli archi costano tutti uguale, ottieni anche i cammini più brevi.

Tempo O(V + E) Spazio O(V) Coda FIFO Iterativa per natura

Ripasso lampo sui grafi

Un grafo è un insieme di nodi (V) collegati da archi (E). Nel codice lo rappresenti quasi sempre con una lista di adiacenza: per ogni nodo, l'elenco dei vicini. In JavaScript è un oggetto o una Map, in Python un dict di liste. Negli esempi usiamo il grafo dell'animazione, non orientato, con i nodi da A a G.

L'idea

Metti il nodo di partenza in una coda e segnalo come scoperto. Finché la coda non è vuota, estrai il nodo in testa, visitalo, e accoda tutti i suoi vicini non ancora scoperti. Siccome la coda è FIFO, prima finisci tutti i nodi a distanza 1, poi quelli a distanza 2, e così via. La distanza di ogni nodo è quella del suo «genitore» più uno.

Il dettaglio che si dimentica più spesso: un nodo va segnato come scoperto quando entra in coda, non quando ne esce. Altrimenti lo stesso nodo può finire in coda più volte, e su grafi densi il lavoro esplode.

Dove lo rivedi sul lavoro

Gradi di separazione in un social graph («amici di amici»), il numero minimo di mosse o di hop in una rete, un crawler che esplora un sito livello per livello, la propagazione di un'invalidazione di cache o di un impatto tra microservizi dipendenti, il flood fill in una griglia. Ogni volta che senti «il più vicino» o «in meno passi», e gli archi pesano uguale, pensa BFS.

Versione iterativa, con la coda

È la forma canonica. Nota l'indice testa in JavaScript e TypeScript: Array.prototype.shift() costa O(n), e su code lunghe trasforma un algoritmo lineare in uno quadratico. In Python si usa collections.deque, che estrae in O(1).

function bfs(grafo, partenza) {
  const distanza = new Map([[partenza, 0]]);
  const ordine = [];
  const coda = [partenza];
  let testa = 0;                       // evita shift(), che è O(n)
  while (testa < coda.length) {
    const u = coda[testa++];
    ordine.push(u);
    for (const v of grafo[u]) {
      if (!distanza.has(v)) {            // segno quando accodo
        distanza.set(v, distanza.get(u) + 1);
        coda.push(v);
      }
    }
  }
  return { ordine, distanza };
}
type Grafo = Record<string, string[]>;

function bfs(grafo: Grafo, partenza: string) {
  const distanza = new Map<string, number>([[partenza, 0]]);
  const ordine: string[] = [];
  const coda: string[] = [partenza];
  let testa = 0;
  while (testa < coda.length) {
    const u = coda[testa++];
    ordine.push(u);
    for (const v of grafo[u] ?? []) {
      if (!distanza.has(v)) {
        distanza.set(v, distanza.get(u)! + 1);
        coda.push(v);
      }
    }
  }
  return { ordine, distanza };
}
from collections import deque

def bfs(grafo, partenza):
    distanza = {partenza: 0}
    ordine = []
    coda = deque([partenza])
    while coda:
        u = coda.popleft()               # O(1), a differenza di list.pop(0)
        ordine.append(u)
        for v in grafo[u]:
            if v not in distanza:      # segno quando accodo
                distanza[v] = distanza[u] + 1
                coda.append(v)
    return ordine, distanza

Si può scrivere ricorsiva?

Sì, ma con un'avvertenza: la BFS è naturalmente iterativa. La ricorsione, sotto il cofano, usa una pila (LIFO), mentre la BFS ha bisogno di una coda (FIFO). Se ti limiti a «chiamare la funzione su ogni vicino» ottieni una DFS, non una BFS.

La variante ricorsiva onesta lavora per livelli: la funzione riceve l'intero livello corrente (la frontiera), costruisce il livello successivo e richiama se stessa su quello. Il risultato è identico alla versione con coda; la ricorsione è profonda quanto il numero di livelli, cioè la distanza massima dalla partenza. È comoda quando ti servono proprio i livelli (per esempio «tutti i nodi a distanza 2»), ma su grafi molto «lunghi», come una catena, può superare il limite di ricorsione del linguaggio.

function bfsPerLivelli(grafo, livello, visti = new Set(livello), ordine = []) {
  if (livello.length === 0) return ordine;   // caso base: frontiera vuota
  const prossimo = [];
  for (const u of livello) {
    ordine.push(u);
    for (const v of grafo[u]) {
      if (!visti.has(v)) { visti.add(v); prossimo.push(v); }
    }
  }
  return bfsPerLivelli(grafo, prossimo, visti, ordine);
}

Complessità

VersioneTempoSpazio extra
Iterativa con codaO(V + E)O(V)
Ricorsiva per livelliO(V + E)O(V) + profondità di ricorsione pari al numero di livelli

Ogni nodo entra in coda al più una volta, e ogni lista di adiacenza viene scorsa una volta: in un grafo non orientato ogni arco viene guardato due volte, una per estremo. Totale lineare nella dimensione del grafo. Con una matrice di adiacenza al posto delle liste, scorrere i vicini costa O(V) per nodo e il totale diventa O(V²).

BFS e cammini minimi

La BFS trova il cammino con il minor numero di archi. Se gli archi hanno pesi diversi (tempi, costi, distanze reali) non basta più: serve Dijkstra, che è una BFS dove la coda diventa una coda di priorità. Per ricostruire il percorso, oltre alla distanza salva il genitore di ogni nodo e risali dalla destinazione.

Esercizi

1. Ordine di visita

Nel grafo dell'animazione, partendo da A e scorrendo i vicini in ordine alfabetico, in che ordine visita i nodi la BFS?

Mostra la soluzione

A, B, C, D, E, F, G. Livello 0: A. Livello 1: B, C. Livello 2: D, E (da B), F (da C). Livello 3: G (da E).

2. Il bug classico

Un collega segna i nodi come visitati solo quando li estrae dalla coda. Il risultato è sbagliato?

Mostra la soluzione

L'ordine e le distanze restano corretti, purché la distanza venga assegnata solo la prima volta. Ma lo stesso nodo può essere accodato più volte (in questo grafo E entrerebbe da B e da C), e nel caso peggiore la coda cresce fino a O(E) invece di O(V). Segnare all'accodamento è più efficiente e più semplice da ragionare.

3. Perché non una ricorsione «normale»?

Cosa ottieni se scrivi visita(u) che, per ogni vicino non visto, chiama subito visita(v)?

Mostra la soluzione

Una DFS. La chiamata ricorsiva scende sul primo vicino e ci resta finché non ha finito tutto quel ramo: è il comportamento di una pila, non di una coda.
